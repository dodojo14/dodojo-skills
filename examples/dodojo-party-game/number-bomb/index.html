    Full rules
    1. Players: 2–10, taking turns in seat order (P1, P2, …). The lit lamp shows whose turn it is.
    2. The bomb: at the start of each round the box hides a random number in the range (1–100 by default). Nobody can see it.
    3. Calling: punch in a number and press OK. It has to be inside the range. Miss, and the range shrinks to the bomb's side: if the bomb is 42 and someone calls 60, the range becomes 1–59; a call of 30 after that makes it 31–59.
    4. Bad calls don't count: a number outside the range, or OK with nothing typed, just shakes the readout. The same player tries again.
    5. One number left: that number is the bomb, and whoever is up has to call it.
    6. Boom: whoever calls the bomb loses, does a forfeit if forfeits are on, and starts the next round.
    7. Tally: the game counts how many times each player blew up tonight. "Reset tally" clears it.
    8. Tip: while the range is wide, numbers near the edges are safer; with three or four left, the pressure passes to the next player.

    Close it halfway through and it opens on the same call next time. Each round's bomb comes from a random seed saved with the round.
